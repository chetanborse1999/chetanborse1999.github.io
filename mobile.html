ComFree-Sim

ComFree-Sim is a GPU-parallelized analytical contact physics engine for scalable contact-rich robotics simulation and control. The method uses a complementarity-free formulation and a prediction-correction update in the dual cone of Coulomb friction.

In dense contact scenes, the engine delivers significantly higher throughput while preserving stable contact behavior for manipulation and control loops, making it practical for fast policy evaluation and MPC rollouts.

  • Designed for parallel execution with NVIDIA Warp.
  • Maintains a MuJoCo-compatible interface for easier adoption.
  • Targets high-contact tasks like pushing, grasping, and clutter interaction.

Sampling Based MPC for Manipulation

Developed a sampling-based MPC pipeline for contact-rich manipulation using fast parallel rollouts. The controller evaluates thousands of trajectory candidates and selects action sequences that satisfy contact stability and task completion constraints.

Integrated with ComFree-Sim to improve rollout speed under frictional contact, enabling more frequent replanning and better robustness against disturbances.

MPC manipulation benchmark: multi-object contact interactions.

Path Planning for AUV

Implemented a 2D planning and navigation stack for autonomous underwater vehicles with A* based global planning and local obstacle handling. Combined DVL and IMU data streams to improve dead-reckoning accuracy in low-visibility conditions.

Validated planning behavior in complex environments with static and dynamic obstacles and tuned recovery behavior for narrow corridors.

AUV mission playback: waypoint tracking and obstacle avoidance.

Debris Detection using Swarm Robots

Built decentralized map-sharing and debris localization algorithms for multi-robot teams. Each agent performs local detection and periodically fuses global occupancy updates for collaborative coverage.

The system focuses on scalable coordination with low communication overhead and reliable identification of debris hotspots.
