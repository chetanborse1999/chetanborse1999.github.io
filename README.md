# Student Portfolio Website

This is my personal portfolio website showcasing my education, projects, research, professional experience, activities, and hobbies.

## Features

- Responsive design
- Dark mode toggle
- Smooth scrolling navigation
- Sections: Intro, Education, Professional Experience, Projects, Research, Activities, Hobbies
- Social links: LinkedIn, GitHub, Google Scholar, Resume

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Deployment

This website is designed to be deployed on GitHub Pages. Simply push the code to your GitHub repository and enable Pages in the repository settings.

## Customization

To customize this portfolio:

1. Update the content in `index.html`
2. Modify styles in `css/style.css`
3. Adjust JavaScript functionality in `js/script.js`
4. Replace placeholder links with your actual profiles
